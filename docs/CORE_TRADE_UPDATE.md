# 燕渡核心交易更新

2026 年 10 月 13 日，本轮围绕发布、查找、联系、预订与成交完善交易流程。开发基线为 `e50aef549d47a2d5db8b48dc0527f0a8b9862996`，开发分支为 `codex/core-trade-update`。这份记录描述本轮代码，实际服务器部署情况见 [部署记录与更新清单](DEPLOYMENT_CURRENT.md)。

## 已实施的产品规则

| 功能 | 行为 |
| --- | --- |
| 无图发布 | 新建、编辑与批量草稿发布统一允许 0–3 张图片。未上传图片时显示“暂无图片”，保留文件格式、数量和图片归属校验。 |
| 商品撤回 | 仅卖家可撤回；存在待处理申请、预订或待确认收货交易时拒绝撤回。撤回后不再公开展示，已有聊天和成交记录保留。重复撤回不会重复修改。 |
| 成交后再发布 | 有已售或已确认收货会话的商品不能直接重新上架。确认成交后“再发一件”复制到草稿，卖家核对后发布新商品。误标已售且无成交记录可恢复售卖。 |
| 交易状态 | 从聊天、商品管理或已售反馈入口标记售出，均同步预订会话并结束其他待处理申请。取消旧预订不会重新公开审核隐藏的商品。 |
| 商品可见性 | 普通列表、收藏列表与公开详情不展示审核隐藏或已撤回商品。本人管理和管理员审核仍可读取；旧匹配通知显示失效占位并移除原商品描述及匹配证据。 |
| 聊天查看商品 | 会话顶部商品摘要可打开详情；返回后保留当前聊天与输入草稿。失效商品保留状态提示。 |
| 搜索 | 顶部搜索按当前商品或求购页面执行；页面切换保留关键词。两类关键词搜索统一大小写、空格分词和同义词处理，多个关键词之间为“同时满足”。 |

撤回目前只覆盖正式商品。草稿已有删除功能，求购仍沿用关闭逻辑，聊天记录不新增删除入口。随后实施的有效期选项、求购关联代蹲及邮件提醒见 [后续功能更新](FOLLOWUP_FEATURES.md)，本页保留首轮交易更新的接口与验证记录。

## 接口与数据兼容

- `DELETE /api/v1/items/{id}` 返回撤回后的商品，状态为 `WITHDRAWN`，不物理删除数据库记录或关联图片。
- `POST /api/v1/items/{id}/duplicate` 返回新的待发布草稿，需要原商品成交已确认，且无未完成交易。
- 商品响应增加 `can_relist`、`can_withdraw`、`can_duplicate`，供界面展示当前允许的操作；后端仍独立检查每项操作。
- 求购搜索关键词上限与商品搜索统一为 120 字；其结果仍为现有列表格式，未改变排序与 100 条结果上限。
- 没有新增数据库表或字段。`WITHDRAWN` 使用原商品状态列，但仍属于新的数据语义：旧版本公开查询不识别该状态，不能直接回退到 `e50aef5`。

## 验证结果

后端回归于 2026 年 10 月 13 日执行，**101 项通过，用时 45.32 秒**。覆盖权限隔离、图片归属、无图发布、撤回后的列表与详情、通知脱敏、多买家申请、重复操作、真实图片商品成交后复制发布，以及旧数据库升级测试。测试使用隔离的 SQLite 数据库与本地模型模式，不连接生产数据。

并发回归使用真实第二连接，在请求读取会话后提交售出状态，验证取消操作重新读取会话并拒绝覆盖已成交记录。该用例验证状态重读，PostgreSQL 的实际行锁阻塞行为仍需单独验证。

现有测试临时目录在本机出现访问权限错误，因此本次指定工作树 `output/` 下的全新临时目录运行；未更改系统目录权限。

前端 TypeScript 检查与 Vite 构建已通过。浏览器使用隔离的本地数据库验收，已验证：

- 电脑端多关键词及连续空格搜索；商品与求购页面切换保留关键词，在求购页提交搜索后仍停留该页。
- 无图商品新建、编辑、草稿发布与占位显示；撤回确认可取消或执行，撤回后不再显示编辑、重新上架操作。
- 聊天顶部打开商品详情并返回，未发送草稿保留；待确认收货时不提供重新上架、复制或撤回，确认成交后可复制为预填草稿并保存。
- 复制草稿发布后生成新的在售商品，草稿从待发布列表移除，原商品仍为已售且不能重新上架。
- 390 × 844 手机视口中，商品占位、聊天输入和发送按钮可见；实际发送成功，刷新后消息历史不再跳回顶部。打开消息举报表单时，举报、取消及聊天发送控件均可达，验收未提交举报。
