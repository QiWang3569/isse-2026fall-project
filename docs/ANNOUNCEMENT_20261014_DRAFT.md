10月14日「燕渡」更新公告

亲爱的北大师生：

燕渡已于10月14日19:46完成功能更新与优化，具体内容如下。

【更新内容】

1. 新增图片聊天功能。站内聊天支持图片及图文消息。聊天图片仅供会话参与者查看，涉及举报的图片可由管理员审核。
2. 新增未读消息邮件提醒。“未读站内信邮件提醒”默认开启，用户可在个人主页调整，消息持续未读约5分钟后，系统将向注册邮箱发送提醒。同一会话的多条未读消息合并发送，两次提醒至少间隔30分钟。该功能可随时关闭或重新开启。邮件不附带聊天图片，请在站内查看并回复。
3. 新增商品撤回与再次发布功能。卖家可撤回商品，已有聊天及交易记录予以保留；存在进行中的交易时，须先处理相关交易。成交确认后，可通过“再发一件”创建新的发布草稿。

【优化内容】

1. 实现求购与代蹲同步。发布求购后，系统自动创建对应的代蹲任务；修改条件、暂停或结束需求时，两者同步更新。已有私密代蹲可发布至求购看板。
2. 调整发布期限与任务数量限制。商品、求购及代蹲不再自动到期，同时取消最多开启5个活跃代蹲的限制。需求满足后，请及时结束任务。
3. 简化发布要求。商品支持无图发布，也可上传最多3张照片；求购的分类、预算和描述均可选填。
4. 优化聊天操作体验。从聊天窗口打开商品详情后返回，未发送的文字将予以保留。
5. 完善交易状态校验。商品售出且等待买家确认收货期间，不可直接重新上架；加强多人同时操作时的状态校验，避免旧操作覆盖已完成的交易状态。
6. 统一商品与求购页面的搜索栏，移除重复入口，根据当前页面切换提示文字和搜索对象；搜索关键词标签移至“只看在售”右侧。同时调整深色界面及手机端聊天布局。

本次更新保留已有账号、商品、需求及聊天记录。如在使用过程中遇到问题，欢迎通过站内反馈。
