- [ ] C2 通知与站内消息分离：统一消息中心，或在铃铛通知里提供“去站内消息”快捷入口。
- [ ] C4 管理员审核入口隐蔽：为管理员提供明确的“审核工作台”入口和待办数量角标。
- [ ] C5 “反馈已售”与“举报问题”易混淆：用分组和文案区分“已售出反馈”与“违规举报”。
- [ ] C7 个人中心功能折叠过多：移动端用底部标签栏或抽屉聚合高频入口。
- [ ] C8 无搜索结果空状态引导：强化 CTA，点击后带入当前搜索条件。
- [ ] C9 交易状态两处口径统一：统一“预订 / 已售 / 取消”的状态文案与操作入口。
- [ ] C10 演示账号与正式登录共存说明：明确“演示账号仅本地”，正式环境隐藏演示入口或给出迁移提示。
- [ ] C11 表单校验提示：关键字段即时校验并高亮，减少“提交后才报错”。
- [ ] C12 时间与价格展示：补充到期提醒与状态徽标，统一金额格式（如两位小数）。
